# SDB Energia — Site institucional

Mesma estrutura do projeto solar-cruz (HTML + CSS + JS puro). Editar em `src/partials/` e rodar `node build.js`.

## Fotos (adicionar em assets/img/)
Enquanto não existirem, o site mostra uma ilustração solar automática.
- `brand/logo.png` (opcional: trocar o logo.svg provisório pelo oficial e ajustar header/footer)
- `projects/hero.jpg` (fundo do topo e dos benefícios), `projects/residencial.jpg`, `comercial.jpg`, `agro.jpg`, `assinatura.jpg`
- `projects/p1.jpg … p8.jpg` (aba "On Grid/Off Grid/Híbrido" e etapas "Como funciona")
- `team/equipe.jpg` (seção Sobre)
